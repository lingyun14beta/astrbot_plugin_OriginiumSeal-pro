# OriginiumSeal-pro - 源石封印插件

这是一个 AstrBot 插件，当用户发送"制作源石头像"指令时，会将指定用户的头像添加源石封印效果。(ps:明日方舟)

> ⚠️ 仅支持 OneBot (aiocqhttp) 平台

## 访问统计

<a href="https://count.getloli.com/"><img src="https://count.getloli.com/get/@:zhewang-OriginiumSeal-pro?theme=moebooru"></a>

## 功能特点

- 自动处理指定用户头像（若没有指定则默认发送者）
- 添加半透明源石封印效果
- 实时返回处理后的图片
- 支持冷却机制，防止频繁触发

## 使用方法

发送以下指令：

制作源石头像         # 处理自己的头像
制作源石头像 @某人   # 处理指定用户的头像

## 安装方法

在插件市场中填入仓库链接：

https://github.com/zhewang448/astrbot_plugin_OriginiumSeal-pro

## 依赖

依赖已包含在 AstrBot 本体中，无需额外安装：

- Pillow
- aiohttp
